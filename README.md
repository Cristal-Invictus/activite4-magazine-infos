# Magazine Infos - Activité 4

Projet Flutter réalisé dans le cadre de l’**Activité n°4** du cours de Développement Mobile.

Ce dépôt présente l’évolution de l’application **Magazine Infos** entre les versions **4.1** et **4.2**.

## Versions
- **Branche `activite-4.1`** : première version avec `MaterialApp`, `Scaffold`, `AppBar`, image locale et `FloatingActionButton`.
- **Branche `main`** : version 4.2 enrichie avec `PartieTitre`, `PartieTexte`, `PartieIcone` et `PartieRubrique`.

## Ressources
Les images locales sont placées dans `assets/images/` et déclarées dans `pubspec.yaml`.

## Lancer le projet
```bash
flutter pub get
flutter run
```

Si les dossiers de plateforme Flutter ne sont pas encore présents après clonage :
```bash
flutter create .
flutter pub get
flutter run
```
